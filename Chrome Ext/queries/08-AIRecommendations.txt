--------------------------------------------------------------------------------
NO ADDITIONAL API CALLS — pure derivation from store data
--------------------------------------------------------------------------------
This tab uses NO direct Jira API calls.
Recommendations are generated by analyzing the output of:
  - calculateTopStories(issues)   → stories with most bugs
  - calculateAgeingItems(issues)  → critical/blocker issues breaching SLA
  - calculateProjectHealth(issues) → overall RED/GREEN health drivers

All underlying data comes from the main FETCH_JIRA call with expand=changelog.

--------------------------------------------------------------------------------
RECOMMENDATION GENERATION LOGIC
--------------------------------------------------------------------------------
generateAIRecommendations(issues, topStories, ageingItems) produces up to 3 cards.

RECOMMENDATION 1 — Top Story with Critical/Blocker Bugs:
  Condition: topStories[0] with criticalCount + highCount > 0
  Priority:  Critical
  Category:  Bug Concentration
  Message:   "N critical/blocker bugs on story <storyKey>. Immediate triage needed."
  bugCount:  topStories[0].criticalCount + topStories[0].highCount
  impactPercent: min(100, (criticalCount/bugCount) * 100)
  affectedModules: unique modules from topStories[0].bugs

RECOMMENDATION 2 — SLA Breached Critical Issues:
  Condition: ageingItems with ageingStatus = AGED (SLA breached)
  Priority:  Critical | High (based on count)
  Category:  SLA Breach
  Message:   "N critical/blocker issues have breached SLA thresholds."
  bugCount:  count of AGED items
  impactPercent: min(100, agedCount * 15)

RECOMMENDATION 3 — High Reopen Rate:
  Condition: issues where reopenCount > 0
  Priority:  Medium | High
  Category:  Quality Regression
  Message:   "N issues reopened — indicates unresolved root causes."
  bugCount:  reopened issue count
  impactPercent: min(100, reopenedCount * 10)

ACTION ITEMS (bullet points per recommendation):
  • Specific actionable steps derived from the data
  • E.g. "Assign P0 reviewer to <module>", "Run regression suite on <story>"

AFFECTED MODULES:
  Derived by extracting issue.module from the bugs in each recommendation group.
  De-duplicated and displayed as tags.

--------------------------------------------------------------------------------
DISPLAY
--------------------------------------------------------------------------------
  Up to 3 recommendation cards (Critical → High → Medium)
  Each card: priority tag, category tag, title, description,
             impact percent progress bar, bugCount + affectedModules,
             action items list
